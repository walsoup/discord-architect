Quick Discord Setup:

  1. Go to Discord Developer Portal > Bot > Copy Token.
  2. Ensure OAuth2 permissions: Manage Channels, Manage Roles, View Channels, Send Messages.
  3. In Discord, go to Server Settings > Roles and drag the bot's role to the top.
  4. Enable Developer Mode in Discord, right-click server > Copy Server ID.
